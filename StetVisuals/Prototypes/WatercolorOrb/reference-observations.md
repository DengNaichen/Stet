# OpenAI orb 原片逐帧观察

来源：[Dev Valladares 发布的设计展示](https://www.instagram.com/reel/DE4HSi2xAKa/)。读取浏览器已播放的视频轨进行分析；源视频为 720 × 1280，30 fps，40.9 秒。

## 检查范围与证据

- 先查看 8–37 秒逐秒总览，定位变化明显的时段。
- 重点逐帧查看 16.133–17.100 秒（帧 484–513）以及 29.700–30.467 秒（帧 891–914），相邻帧间隔 1/30 秒。
- keyframes.png 为选出的关键帧，并非连续帧；连续帧图为 transition-every-frame.png 和 growth-every-frame.png。
- 图片裁切自源视频同一位置（310 × 310），仅等比缩放以排版，没有调色或补绘。帧编号从 0 开始。

## 可直接观察的现象

1. 16.000–16.200 秒，左下浓蓝迅速扩张，整片色块连成一体。
2. 16.533–16.867 秒，浓蓝明显退去，原位置仍能看到浅蓝纹理。流动与颜色浓淡在同时变化，不能只用整体上下移动解释。
3. 17.000–17.100 秒，左侧局部浓蓝在三帧间隔内明显加深。画面仍连续，没有硬切。
4. 29.700–30.467 秒，同样能看到蓝色内部的浓度变化；蓝白边界、内部深浅边界的运动幅度并不一致。

## 对当前复刻的启示（实现建议，并非原作者算法）

把较慢的底层流动，与较快的浓蓝显隐分开控制。浓蓝需要同时改变局部覆盖面积与浓度，允许迅速退去，再从局部连片显现。白色过渡带继续随整体流动。

当前原型的 level 先经 55/320 ms 平滑，颜色随后又经 120/580 ms 平滑（均为指数时间常数），还保留固定的深蓝混合权重，因此容易留下长尾，削弱快速显隐。下一步应先建立单独的浓蓝控制，再映射音量包络、起音和频段特征；单纯添加 FFT 不会自动产生这种视觉节奏。

本次视频轨没有音轨，因此这些观察支持视觉运动结论，不能据此确定原作具体用了哪些声音特征。本次未修改现有 HTML 或 shader。
