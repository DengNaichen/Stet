## 如何引用这些证据

引用时带上调查日期、代码 / 来源版本、实际验证范围和未验证项。历史结论不随时间自动失真，但它对当前问题的适用性需要确认。

已有结论被后续工作替代时，在本索引连接后续文档、代码或 issue；不要回写旧实验结果，使它看起来一直正确。临时日志、非固定链接或未提交修改导致无法重现时，明确标注证据缺口。

只有产品或架构选择已明确、并且有必要记录权衡时才另写 ADR，引用相应研究作为依据。未采纳建议仍是建议，不能包装成既成决策。
