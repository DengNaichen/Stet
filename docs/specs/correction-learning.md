# 功能规格：修正学习

**创建**：2026-11-07（2026-11-14 更新为结束单次快照结算 + 改写模型守门提取）
**状态**：Draft

**范围**：macOS 语音听写自动粘贴；词典数据模型由 macOS / iOS 共享。iOS 与选中文本改写不做修正学习。
**边界**：本 spec 拥有观察窗口、最终快照提取、本地粗筛、改写模型守门判定与本地硬校验，以及“关闭个人词典或未启用改写服务时停止自动学习”。词条的存储、来源标记的持久化、iCloud 同步、以及词典向转写和改写提供哪些词，见[个人词典](personal-dictionary.md) spec。粘贴本身见[文本交付](text-delivery.md) spec；`finalText` 的含义见[听写历史与统计](dictation-history-and-stats.md) spec；辅助功能缺失时静默跳过见 [权限与恢复](permissions-and-recovery.md)。

## 术语

- **插入区域**：按粘贴前输入框的前后文本书签定位出的、本次粘贴的文本所在范围。
- **观察窗口**：粘贴后 Stet 只读观察插入区域并维护最新非空快照的一段时间（最长 30 秒）。
- **自动词条**：由修正学习加入词典、来源为 `automatic` 的词条；手动加入的为 `manual`。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 纠错专有名词与人名，发送后自动认得（优先级：P1）

作为用户，我把 Stet 粘贴进来的 `拍图` 改成 `Python`（或把误听的人名、术语改正）并发送/离开后，希望 Stet 记住 `Python`，下次直接写对。

**独立测试**：在可读取的输入框中听写并自动粘贴，把误识别的术语改对后按 Return（或切走焦点），确认后台异步提取后词典新增带星光图标的 `Python`。

**验收场景**：

1. **Given** 粘贴结果已确认出现在输入框，**When** 我把 `拍图` 改为 `Python` 后按 Return 发送（即使聊天框随即被清空），**Then** 词典新增自动词条 `Python`。
2. **Given** 观察进行中我用中文输入法打字并在候选词中间停顿，**When** 尚未按完成键或结束观察，**Then** 中途半成品不会触发模型请求或写入词典。
3. **Given** 我在编辑器中改正了 `herder → Herdr` 后切换窗口、移开焦点、开始下一次听写或满 30 秒，**When** 观察结束，**Then** 结算最后一份非空快照并学习 `Herdr`。

---

### 用户故事 2 - 宁缺毋滥，不学日常改口与噪音（优先级：P1）

作为用户，我只是改口换了时间数字、替换日常词、补写半句话、删减或改标点，不希望词典混入日常词或长短语干扰后续识别。

**验收场景**：

1. **Given** 已确认插入，**When** 我只做纯追加、纯删除、只改标点 / 空白 / emoji，或没按完成键就把输入框删空，**Then** 本地直接结束，不发起模型请求。
2. **Given** 已确认插入，**When** 我把 `明天` 改为 `后天`、把 `3` 改为 `4`、或把日常词 `那里` 改为 `家里`，**Then** 守门模型判定 `ignore`，不创建词条。
3. **Given** 模型返回候选词，**When** 某个候选词不是最终文本的精确子串、在原文中已同频存在、或超过词长上限，**Then** 本地硬校验直接丢弃该词。

---

### 用户故事 3 - 手动词条优先与开关约束（优先级：P2）

**验收场景**：

1. **Given** 已有手动词条，**When** 自动学到同一词，**Then** 不覆盖手动来源。
2. **Given** 已有自动词条，**When** 我手动添加同一词，**Then** 提升为手动来源并采用手动拼写。
3. **Given** 个人词典已关闭，或改写服务未启用 / 缺少可用配置，**When** 粘贴或结束观察，**Then** 不写入自动词条；模型请求超时或报错时静默忽略。

## 需求 *(必填)*

### 功能需求

**观察与快照结算**

- **FR-001**：仅在语音听写自动粘贴（`Cmd+V`）事件前捕获前台目标应用、当前焦点辅助功能元素、原值和 UTF-16 选区；密码框（`AXSecureTextField`）不观察；选中文本改写不触发观察。
- **FR-002**：粘贴后最多等待 2 秒确认预期插入结果实际出现在输入框中；未确认则放弃观察。
- **FR-003**：观察窗口最长 30 秒，轮询间隔约 200 ms。观察期间只在内存刷新“最后一份非空插入区域快照”，中途不入库。
- **FR-004**：按下不带 Shift 的 Return / Enter / Tab、目标应用或焦点元素改变、窗口外非空文本改变、开始下一次听写或满 30 秒时，单次结算最后快照并结束观察。按下完成键后即使目标聊天框已被清空，仍使用刚保存的最后非空快照结算；未按完成键而输入框变空视为删除/撤销，不学习。
- **FR-005**：粘贴事件发送失败或粘贴任务被取消时，直接丢弃当前观察，不结算。

**本地粗筛与守门模型提取**

- **FR-006**：结算时本地先过滤无变化、纯标点/空白/emoji 变化、纯删除（词内删多打字母修复除外）和纯句尾续写（拉丁词尾补全除外）；命中过滤时零网络请求直接结束。
- **FR-007**：通过本地粗筛后，只将本次粘贴的 `ORIGINAL` 与插入区域最终 `EDITED` 异步发送给当前已启用的改写服务商及密钥（推理档位压至最低：DeepSeek 关闭思考、OpenAI `minimal`、Google `low`；单次 10 秒超时，不重试，失败静默忽略）。
- **FR-008**：系统提示词采用双重门禁（默认返回 `ignore`）：只有同时属于专有名词 / 人名 / 品牌产品项目名 / 技术术语标识符 / 特定拼写，且属于语音识别纠错或补齐特定术语时，才允许返回 `learn`。
- **FR-009**：入库前执行本地硬校验：仅接受 `decision == "learn"`；候选词不含分句标点与换行、总长不超过 32 字符、空白分词不超过 4 个、CJK 字符不超过 10 个，且在 `EDITED` 中的独立出现次数严格大于在 `ORIGINAL` 中的出现次数。

**来源与隐私边界**

- **FR-010**：原始输入框快照只留在内存；发往用户所选改写服务的内容仅限本次插入区域的前后片段，不上传输入框外部上下文。
- **FR-011**：词条来源（`manual` / `automatic`）的存储、合并优先级与 iCloud 同步见[个人词典](personal-dictionary.md) spec。

## 成功标准 *(必填)*

- **SC-001**：纯追加、纯删除、纯标点 / 空白 / emoji 修改以及未按完成键的清空，模型请求次数为 0。
- **SC-002**：观察期间的中间输入态产生的模型请求与入库词条数为 0；每次粘贴最多触发 1 次结算。
- **SC-003**：非 `EDITED` 精确子串、原文未变化词、超长短语入库数为 0。
