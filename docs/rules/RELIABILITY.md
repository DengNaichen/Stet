# Stet 可靠性规则

本文件记录当前仓库改动风险较高的区域和可靠性硬约束。它回答"在这个项目里，改哪些东西需要格外小心"，不重复通用可靠性建议。

## 高风险改动区域

按风险从高到低排列：

| 区域 | 影响范围 | 为什么风险高 |
|------|----------|-------------|
| 本地转写引擎选择 [RELIABILITY-0001] | 听写可用性 | FluidAudio、FunASR Nano 或 SenseVoice 无法准备时会回退到 Local Whisper。 |
| 听写工作流终止处理 [RELIABILITY-0002] | 媒体与系统静音状态 | workflow 在 deinit 时取消 pending media/start task 并恢复 mute；capture 结束后延迟恢复 mute 和播放。 |
| 自动粘贴完成处理 [RELIABILITY-0003] | 用户剪贴板和输出结果 | 普通权限缺失或粘贴验证失败会恢复临时剪贴板、进行非 transient 复制并返回失败。 |
| optimistic auto-paste profile [RELIABILITY-0004] | 用户剪贴板和完成状态 | 部分验证不可用/失败会被视为成功，剪贴板恢复改为延迟。 |

## 高风险确认边界
