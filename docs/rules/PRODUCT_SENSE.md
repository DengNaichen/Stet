# Stet 产品判断

本文件记录 agent 无法仅从代码中可靠推断出的产品判断。它回答"这个产品承诺什么、给谁用、改动时怎么判断是不是产品回退"。文件路径见 [ARCHITECTURE.md](../ARCHITECTURE.md)。

## 产品身份

Stet 是 macOS 菜单栏听写应用，用最少改写把语音转换为可用文本 [PRODUCT-0001]。

## 目标用户

面向需要从菜单栏以全局快捷键启动听写、再将结果写入当前应用或替换选中文本的 macOS 用户 [PRODUCT-0002]。

## 产品原则

Stet 必须让转录输出贴近说话者意图，并避免不必要的改写 [PRODUCT-0004]。

## 核心体验路径

首次启动引导用户完成权限和听写设置，并选择 Stet account 或自己的 API key [PRODUCT-0003]。

## 反模式

除产品原则所述的意图保真边界外，未核实到独立的产品反模式。

## 和硬约束的关系

本文件帮助判断一个改动是否影响产品体验；技术层面的硬约束分布在各实践文件和 ARCHITECTURE.md 的"硬约束"段。
