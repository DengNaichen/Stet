# StetMobile Development

This directory is private and is built as part of the Stet internal monorepo.

- Use Xcode Beta through the root `make ios-build` target.
- Shared package code lives at `../../Public/Stet/Packages/StetEngine`.
- Shared visual code lives at `../../Public/Stet/StetVisuals`.
- Run formatting and SwiftLint from the monorepo root.
- Keep `.runtime/`, ONNX models, downloaded frameworks, and build products out of Git.
