# Apple Platform Reference

Stet 的 Apple 平台参考库。每个 topic 目录内的 `SKILL.md` 是该 topic 的路由表；详细内容在同级 `skills/` 下。

**用法：** 先在本 index 找到 topic → 只打开对应目录的 `SKILL.md` → 再按需打开单个 `skills/*.md` 文件。不要一次性读取全部 topic。

来源：基于 [CharlesWiltgen/Axiom](https://github.com/CharlesWiltgen/Axiom) 整理（本地快照，待网络恢复后可更新）。
