# Requirements Document: Audio Post-Processing

## Overview

音频后处理功能负责在音频捕获完成后、发送到转录服务之前，对音频文件进行分析和增强处理。

---

## User Stories

### 1. 音频信号分析

**作为** 系统
**我想要** 分析捕获的音频文件以识别语音内容和音频质量
**以便** 决定是否需要增强处理或丢弃无语音的录音

**验收标准：**
- 1.1 系统能够加载 WAV 格式的音频文件并提取样本数据
- 1.2 系统使用 VAD（语音活动检测）识别音频中的语音片段
- 1.3 系统过滤掉持续时间小于 0.4 秒的短语音片段
- 1.4 系统计算语音帧比率（语音时长 / 总时长）
- 1.5 系统计算噪声底噪电平（DBFS）
- 1.6 系统计算语音电平 P75（第 75 百分位数，DBFS）
- 1.7 系统计算整体峰值电平（DBFS）
- 1.8 系统根据分析结果推荐增益调整（dB）

### 2. 无语音检测和丢弃

**作为** 系统
**我想要** 检测并丢弃不包含有效语音的录音
**以便** 避免浪费转录资源和提高用户体验

**验收标准：**
- 2.1 如果音频中没有检测到持续时间 ≥ 0.4 秒的语音片段，标记为无语音
- 2.2 标记为无语音的录音返回 `shouldDiscardAsNoSpeech = true`
- 2.3 系统记录丢弃决策的详细日志（包含分析摘要）

### 3. 语音增强决策

**作为** 系统
**我想要** 根据音频分析结果决定是否需要进行语音增强
**以便** 提高转录质量而不过度处理音频

**验收标准：**
- 3.1 如果推荐增益的绝对值 ≥ 0.5 dB，启用语音增强
- 3.2 如果推荐增益的绝对值 < 0.5 dB，跳过语音增强
- 3.3 如果音频被标记为无语音，跳过语音增强
- 3.4 系统生成语音增强计划，包含目标电平、应用增益、攻击/释放时间等参数

### 4. 语音感知增益处理

**作为** 系统
**我想要** 应用动态增益调整来提升语音清晰度
**以便** 改善转录准确性

**验收标准：**
- 4.1 系统使用帧级分析（20ms 帧，10ms 跳跃）处理音频
- 4.2 系统根据帧 RMS 电平和噪声底噪计算语音置信度
- 4.3 系统应用平滑增益调整（攻击时间 0.12s，释放时间 0.4s）
- 4.4 系统限制增益范围：最大提升 +10 dB，最大衰减 -4 dB
- 4.5 系统应用限幅器防止削波（上限 -1 DBFS）
- 4.6 系统根据信噪比动态调整增益强度

### 5. 音频文件重写

**作为** 系统
**我想要** 将增强后的音频写入新文件
**以便** 保留原始录音并提供增强版本用于转录

**验收标准：**
- 5.1 系统创建临时文件存储增强后的音频
- 5.2 输出格式为 16-bit PCM WAV，采样率与原文件一致
- 5.3 系统返回增强后的文件 URL
- 5.4 系统标记是否重写了音频（`didRewriteAudio`）
- 5.5 如果增强后的样本与原始样本相同，不创建新文件


### 6. 错误处理和降级

**作为** 系统
**我想要** 在后处理失败时优雅降级
**以便** 确保录音仍然可以被转录

**验收标准：**
- 6.1 如果音频文件不是 WAV 格式，直接传递原文件（passthrough）
- 6.2 如果音频文件加载失败，记录警告并传递原文件
- 6.3 如果语音增强失败，记录警告并传递原文件
- 6.4 所有错误都记录详细的错误信息用于调试

### 7. 性能监控和日志

**作为** 开发者
**我想要** 详细的后处理日志和性能指标
**以便** 监控系统行为和调试问题

**验收标准：**
- 7.1 系统记录音频分析摘要（语音帧比率、电平、推荐增益等）
- 7.2 如果启用性能跟踪，记录详细的后处理摘要
- 7.3 系统记录无语音丢弃决策
- 7.4 系统记录音频重写操作（包含输出文件名）
- 7.5 所有日志包含足够的上下文信息用于调试

### 8. 增益计算策略

**作为** 系统
**我想要** 智能计算推荐增益
**以便** 在提升语音清晰度和避免噪声放大之间取得平衡

**验收标准：**
- 8.1 目标语音电平设置为 -20 DBFS
- 8.2 原始增益 = 目标电平 - 当前语音电平
- 8.3 正增益（提升）限制在 +10 dB 以内
- 8.4 负增益（衰减）仅在以下情况应用：
  - 整体峰值 > -1 DBFS，或
  - 语音电平 > -14 DBFS（目标 + 6 dB）
- 8.5 负增益限制在 -4 dB 以内
- 8.6 根据信噪比缩放正增益：
  - 信噪比 ≤ 4 dB：增益缩放为 0
  - 信噪比 ≥ 8 dB：增益缩放为 1
  - 4 dB < 信噪比 < 8 dB：线性插值
- 8.7 最终增益不超过峰值安全限制（-1 DBFS - 当前峰值）

### 9. 帧级分析配置

**作为** 系统
**我想要** 使用合适的帧参数进行音频分析
**以便** 在时间分辨率和计算效率之间取得平衡

**验收标准：**
- 9.1 分析帧长度为 20ms
- 9.2 帧跳跃长度为 10ms（50% 重叠）
- 9.3 VAD 语音概率阈值为 0.8
- 9.4 最小语音片段持续时间为 0.4 秒

### 10. 后处理结果类型

**作为** 系统
**我想要** 返回明确的后处理结果类型
**以便** 调用方知道如何处理结果

**验收标准：**
- 10.1 Passthrough：返回原始文件 URL，未修改音频
- 10.2 Discard：标记为无语音，建议丢弃
- 10.3 Rewritten：返回增强后的文件 URL，标记已重写
- 10.4 结果包含清理 URL 列表（用于后续删除临时文件）
- 10.5 结果包含音频持续时间（如果可用）

## Non-Functional Requirements

### 性能要求
- 后处理延迟应小于录音时长的 20%
- VAD 分析应在 < 500ms 内完成（对于 10 秒音频）
- 增益处理应在 < 200ms 内完成（对于 10 秒音频）

### 质量要求
- 增强后的音频不应引入可听的失真
- 限幅器应防止所有削波（峰值 ≤ -1 DBFS）
- 增益平滑应避免突变和咔嗒声

### 可靠性要求
- 后处理失败不应导致录音丢失
- 所有错误都应被捕获并记录
- 系统应优雅降级到传递原始文件

---

## Dependencies

- **FluidAudio**: VAD（VadManager）、音频转换（AudioConverter）
- **AVFoundation**: 音频文件读写（AVAudioFile、AVAudioPCMBuffer）
- **Foundation**: 文件系统操作、日志记录

---

## Out of Scope

以下功能不在本规范范围内：
- 噪声抑制（降噪）
- 回声消除
- 频谱均衡
- 音高校正
- 时间拉伸/压缩
- 多通道音频处理（仅支持单声道）
- 实时流式处理（仅支持文件处理）
